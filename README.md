# Thực hành tạo Navbar với Bootstrap

Bài thực hành sử dụng Bootstrap 5.3.0 CDN.

## Nội dung
- Navbar nền tối.
- Brand: MyWebsite.
- Menu Home, About, Services và Contact.
- Services có Dropdown gồm Web Design và SEO.
- Navbar tự thu gọn trên màn hình nhỏ.
- Bootstrap Bundle JS giúp nút toggler và dropdown hoạt động.

## Chạy bài
Mở `index.html` bằng trình duyệt hoặc Live Server.

Thu nhỏ cửa sổ trình duyệt để kiểm tra giao diện mobile.
